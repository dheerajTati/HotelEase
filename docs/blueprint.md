# **App Name**: HotelEase

## Core Features:

- User Authentication: Authentication system with JWT for Admin and User roles.
- Room Availability: Allow users to view available rooms based on selected check-in and check-out dates.
- Booking Management: Enable users to book rooms, view booking history, and cancel bookings (optional).
- Admin Dashboard: Admin interface to manage rooms (CRUD operations) and view all bookings.
- Booking Status Updates: Allow admins to update booking statuses (Confirmed / Completed / Cancelled).
- Payment Confirmation: Simulate a payment step and update booking status to Paid upon confirmation.
- Simple Analytics Tool: Provides simple analytics and key figures by presenting total rooms, rooms booked today, total users and upcoming check-ins.

## Style Guidelines:

- Primary color: Calm Blue (#64B5F6) for a serene and trustworthy feel.
- Background color: Light Gray (#F0F4F8) to provide a clean and spacious layout.
- Accent color: Soft Orange (#FFA726) to highlight important actions and calls to action.
- Body and headline font: 'PT Sans' for a modern and warm user experience.
- Use modern and professional icons related to hotels and booking management.
- Rounded corners, soft shadows, and consistent button styles for a polished look.
- Subtle animations on button interactions and page transitions.
